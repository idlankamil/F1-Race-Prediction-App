🏎️ Smart F1 Companion
--------------------------------------
An interactive race prediction and fan hub application featuring real-time race simulations, AI predictions, and a live community pulse, built with React Native and Expo. The app brings Formula 1 data to life with smooth theme transitions and dynamic UI layouts designed for motorsport enthusiasts.

✨ Technologies
--------------------------------------
* React Native
* TypeScript
* Expo
* Tailwind CSS / NativeWind
* FastAPI (Backend Engine)

🚀 Features
--------------------------------------
* Predictive AI models analyzing race outcomes and driver performance
* Interactive driver and circuit selectors with responsive stat layouts
* Live Fan Pulse widgets and real-time chat mockups for race day hype
* Seamless Dark and Light mode customization across all screens
* Built for fluid mobile navigation and real-time data streaming

📍 The Process
--------------------------------------
I've been on a mission to build a tool that solves a massive gap in standard F1 apps—most platforms only show static historical stats, but they don't guide fans through live race strategies or adapt to changing track conditions. I wanted to build something that felt like having an AI race engineer in your pocket. Started simple with the UI layouts in React Native and gradually hooked up the prediction components. When you select a driver or circuit, the interface smoothly updates with tailored AI predictions. Added a dynamic Fan Pulse widget to capture the community's energy during intense race weekends. Hooking up all the state tracking and live data feeds was a challenge, but I'm incredibly happy with how responsive and slick the final experience feels!

🚦 Running the Project
--------------------------------------
1. Clone the repository
2. Install dependencies: `npm install` or `yarn install`
3. Start the backend engine: `uvicorn main:app --reload`
4. Run the mobile development server: `npx expo start`
5. Scan the QR code using the Expo Go app on iOS or Android
